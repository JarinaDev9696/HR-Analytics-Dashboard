# 📊 HR Analytics Dashboard

An interactive HR analytics dashboard that transforms raw employee data into clear, actionable workforce insights. Built with **React** and **Recharts**, it visualizes attrition patterns across 1,480 employee records to help identify where and why employees are leaving.

---

## ✨ Features

- 🏢 **Department-wise filtering** — switch between Overall, Human Resources, Research & Development, and Sales
- 📈 **Live KPI cards** — Total Employees, Attrition Count, Attrition Rate, Avg Age, Avg Salary, Avg Tenure
- 🎓 **Attrition by Education Field** — donut chart breakdown by academic background
- 👥 **Attrition by Age Group** — see which age brackets churn the most
- 💰 **Attrition by Salary Slab** — pay-band level risk analysis
- 📊 **Job Role Distribution by Level** — matrix view across job levels (L1–L5)
- 📉 **Attrition Trend by Years at Company** — tenure-based churn pattern
- 🏆 **Top 6 Job Roles by Attrition** — pinpoint the riskiest roles

---

## 🛠️ Built With

- ⚛️ React
- 📉 Recharts
- 🎨 Custom dark-themed UI
